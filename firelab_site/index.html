    MEASUREMENT RULES

    Preserve first. Interpret carefully.

    01
    Record identity

    FLEX Test # is the record key. Reused secondary hardware identifiers do not remove otherwise distinct tests.

    02
    Missing and approximate values

    Blank and dash values remain missing. Tilde-prefixed values are labeled approximate and excluded from exact-value summaries.

    03
    Reported composition

    Gas fractions are preserved as given. No normalization is applied when their total differs from one.

    04
    Composition field crosswalk

    The PSI CSV keeps the field name “CO”. NASA/TP-2015-216046 defines its report field “CO₂” as ambient carbon-dioxide mole fraction. The first 31 PSI tests match the corresponding NASA Table IX entries across eight fields (248 comparisons, zero mismatches), including PSI “CO” versus report “CO₂”. This supports the mapping in that checked range only; the other 243 PSI rows remain unverified. NASA's report states 284 tests versus 274 PSI rows, an unresolved scope difference.

    05
    Burning-rate unit and method

    The PSI header abbreviates the unit as “mm”. The NASA report defines burning rate in mm²/s as an average constant from a linear fit of droplet diameter squared versus time, shortly after ignition through extinction. FireLab preserves the PSI header and displays the report-documented unit.
