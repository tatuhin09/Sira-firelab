# Software and Dataset License Status

## Current status — 2026-11-13

### Original project software

The repository includes the complete Apache License 2.0 text in the root-level `LICENSE` file.

The project lead confirms that both project contributors — the project lead and Sadia — approved public release of the original SIRA FireLab project and its Apache-2.0 licensing.

The Apache-2.0 license applies to the original project software. It does not override separate rights, licenses, or terms applicable to NASA datasets or other third-party materials.

No contributor legal names or additional copyright ownership claims are invented in this document.

### NASA datasets

PSI-69 FLEX Version 5 repository metadata identifies the investigation license as CC0-1.0.

PSI-25 BASS-II Version 4 provenance identifies CC0-1.0 at investigation metadata scope. This is not an independent file-level legal review. The project preserves this limitation.

Dataset licensing is separate from the original FireLab software license.

### Other third-party materials

Third-party datasets, code, text, images, and other resources remain subject to their own applicable licenses and permissions. Their provenance and citations must be preserved. The project-level Apache-2.0 license must not be represented as relicensing third-party materials.

### Historical release baseline

The frozen release baseline dated 2026-11-12 recorded the software license as pending and the repository-level LICENSE file as absent. That historical record remains unchanged. The current status is updated above following the team's licensing decision.
