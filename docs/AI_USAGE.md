# AI Usage Disclosure

## AI-assisted development

OpenAI ChatGPT and Anthropic Claude were used as AI-assisted development tools during creation of SIRA FireLab.

Their assistance included project planning and architecture discussions, software drafting and code refinement, debugging, test design and review, verification support, and documentation drafting.

AI-assisted code and suggestions were reviewed and tested by the project team before inclusion. Specific model-version identifiers were not consistently recorded and are not asserted here.

## Data and numerical analysis

The experimental datasets originate from NASA Physical Sciences Informatics source releases; they were not generated by an AI model.

Parsing, source validation, registered numerical calculations, cohort summaries, rankings, and PSI-25 evidence-synthesis artifacts are produced by deterministic software. The PSI-25 synthesis manifest records `llm_used: false`.

AI tools were not used to invent or alter NASA measurements, source identifiers, experimental record counts, sample sizes, or deterministic numeric outputs.

## Submission disclosure

The NASA submission's designated AI/SI tools field and project metadata must both acknowledge ChatGPT and Claude and describe their software-development roles. This disclosure should be checked against every team contributor's actual tool use before final submission.

## Responsibility

The project team remains responsible for source attribution, software review, provenance, scientific interpretation, project claims, and submitted materials.
